# Sons do Nexo (pack discord-sounds-mod)

Arquivos oficiais do pack:

| Arquivo | Uso |
|---------|-----|
| `connect.mp3` | Entrar na call / toque |
| `disconnect.mp3` | Sair / hangup |
| `mute.mp3` / `unmute.mp3` | Microfone |
| `deafen.mp3` | Ensurdecer |
| `stream_start.mp3` / `stream_stop.mp3` | Compartilhar tela |
| `notification.mp3` / `ping.mp3` | Mensagem |

Atualize colocando o RAR em `%USERPROFILE%\Desktop\discord-sounds-mod.rar` e rode `npm run build`.
